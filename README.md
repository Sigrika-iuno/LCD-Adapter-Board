## ⚠️ 重要注意事项

> **1. 安装顺序（极其重要）**  
> 组装时请务必 **先将铜柱/螺丝固定在转接板和屏幕上**，**最后再插入排针**！  
> 若先插排针再锁螺丝，容易导致 PCB 受力变形，造成虚焊或焊盘撕裂。

> **2. 背光控制逻辑**  
> 本转接板的背光控制引脚为 **高电平有效（High-level active）**。  
> 即：**必须将对应 GPIO 引脚拉高（输出高电平）才能点亮屏幕背光**，低电平则会关闭背光。请在初始化代码中特别注意此点。

## 📦 制板文件

Gerber 制板文件位于 [`Gerber/`](Gerber) 文件夹内


> 组装时 **先将铜柱/螺丝固定在转接板和屏幕上**，**最后再插入排针**！  

> LCD的背光控制引脚为 **高电平有效（High-level active）**。
